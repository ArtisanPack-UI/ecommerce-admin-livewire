# Reference

Lookup material for the admin: the hooks it applies and uses, its public PHP API, its Artisan commands, its configuration keys, and the ability each screen and action checks.

- [Hooks](reference/hooks.md): every filter the admin applies, the hooks from other packages it uses, and the browser events its components exchange.
- [PHP API](reference/php-api.md): every registry, the Livewire concerns for your own components, the contracts and base classes you implement, and the support classes you can call.
- [Artisan commands](reference/commands.md): `ecommerce-admin:install`, `ecommerce-admin:prune-imports`, the deprecated `ecommerce-admin:sync-permissions`, and the engine commands the admin relies on.
- [Configuration](installation/configuration.md): every key in `config/artisanpack/ecommerce-admin-livewire.php`.
- [Authorization](authorization.md): the engine ability behind each screen and Livewire action.
- [Screens](usage/screens.md): every admin path and route name.
